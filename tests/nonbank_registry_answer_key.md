# Answer key: Nonbank Registry rescission

## Facts the tool must get right
- Document type and status: Final rule (critical)
- Publication date: October 29, 2025
- Effective date: October 29, 2025, on publication (critical)
- Compliance date: Not stated
- Comment deadline: Not applicable. Final rule; comments were taken on the earlier proposal.

## Applicability
- Nonbank, more than 5,000 loans: Partly in scope. Relief: no longer required to register covered orders or file annual written statements. Practical effect depends on whether the servicer had a covered order or registered. (critical)
- Bank, more than 5,000 loans: Out of scope. The rule only ever applied to nonbank covered persons. (critical)
- Small servicer (5,000 or fewer): Loan count is irrelevant here. Applicability depends on institution type, not portfolio size.

## What is not changing
- The document relies heavily on NMLS as an existing source of enforcement order information. A good summary should mention this as part of the Bureau's reasoning.
- The tool should not claim the rule changes any NMLS or state reporting obligations.
- State licensing and investor requirements to track enforcement orders are not otherwise addressed in the document (not in document text; tool not expected to catch).

## Expected priority
- Nonbank: High, per the current prompt rule (already in effect).
- Bank: None or Low, since out of scope.
- My view: Medium for nonbanks. It's relief, not new work, but retiring the process still needs to be done properly: remove the filings from the compliance calendar, retire the attesting executive role, update procedures and board reporting, and document the decision. Order tracking for state and NMLS purposes should continue. No action for banks.

## Things the tool must not do
- Tell a bank it must take action under this rule (critical)
- Apply the 5,000-loan small servicer test to this rule (critical)
- Invent a compliance date
- Treat the rescission as a new obligation rather than relief (critical)
- Say the obligation to register orders still exists
- Claim this document also withdraws the separate form contract registry proposal
- Recommend that nonbanks stop tracking enforcement orders altogether
